# Legal Content Guide

This project is a prototype decision-support system. It must not be used as an operational legal authority.

## Content standards

Any future legal entry must include:

- Act or instrument title
- Section or rule reference
- Exact source
- Source reference
- Effective date
- Verification date
- Version
- Verification authority
- Status

If information is incomplete, the application must show:

- "NO VERIFIED LEGAL BASIS FOUND IN THE CURRENT DATABASE."
- "CONDITIONAL — VERIFY ALL STATUTORY CONDITIONS BEFORE EXERCISE."
- "VERIFY WITH COMPETENT LEGAL/COMMAND AUTHORITY."

## Approved process

1. Verify the source document or authoritative notice.
2. Record the exact source, reference, effective date, and verification authority.
3. Enter a version and status.
4. Attach a keyword summary for search.
5. Add related powers, offences, scenarios, and procedures.
6. Review before publishing in the database.

## Demo content rule

The initial database uses only clearly labelled DEMO DATA. Real legal records must replace these placeholders before operational use.
